GETTING STARTED

Set up your demo

This project runs in fixture mode until you add PayPal Sandbox credentials and buyer-side setup.

  1. Sign up at developer.paypal.com and create a Sandbox REST app.
  2. Create Sandbox personal (buyer) and business accounts; send a test payment from buyer to business.
  3. API-based buyer dispute creation needs the DISPUTE_CREATE scope enabled by PayPal, buyer consent, and an auth assertion. This can take time; follow PayPal's current Sandbox test guide.
  4. Copy .env.example to .env, enter credentials, then set PAYPAL_MODE=sandbox.
  5. For AI-assisted drafting, set AI_PROVIDER=gemini and GEMINI_API_KEY, plus AI_MODEL and AI_MODEL_FALLBACKS to survive a model outage. Without a key, Recourse labels a rules-based draft instead.
